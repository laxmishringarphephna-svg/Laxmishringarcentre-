🎉 Wallpaper Manager

लक्ष्मी श्रृंगार सेंटर की वेबसाइट का त्योहार वाला wallpaper बदलें।

सुरक्षा: अपना GitHub token इस पेज में केवल अस्थायी रूप से डालें। उसे इस वेबसाइट के कोड में सेव नहीं किया जाता। Token किसी को चैट में न भेजें।
JPG/PNG/WebP/GIF • बेहतर परिणाम के लिए 8 MB से कम रखें।

कैसे इस्तेमाल करें?

  1. GitHub से बनाया हुआ नया token अपने पास रखें।
  2. ऊपर token डालें।
  3. नया wallpaper चुनें।
  4. Wallpaper बदलें दबाएँ।
  5. कुछ सेकंड बाद वेबसाइट खोलकर देखें।

यह सिस्टम repository में केवल wallpaper.jpg फाइल को बदलता है। आपकी मुख्य वेबसाइट की बाकी फाइलें नहीं बदलता।
